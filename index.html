1. Apache Sling Models: Clean Separation of Concerns

In legacy AEM, JSP scripts often contained tangled business logic and JCR query traversal. Modern AEM strictly utilizes Sling Models — POJOs annotated with @Model that automatically map JCR ValueMaps into strongly-typed Java objects.

Engineering Principle: Always use DefaultInjectionStrategy.OPTIONAL to protect page rendering against unconfigured dialog values during authoring.

Component: CodeSnippet · ArticleHeader.java
JAVA 11 (OSGi Bundle) 
@Model(adaptables = Resource.class, defaultInjectionStrategy = DefaultInjectionStrategy.OPTIONAL)
public class ArticleHeader {

    private static final int WORDS_PER_MINUTE = 200;

    @ValueMapValue
    private String title;

    @ValueMapValue
    private String author;

    @ValueMapValue
    private Calendar publishDate;

    @ValueMapValue
    private String articleText;

    // Calculates estimated reading time automatically from word count
    public String getReadTime() {
        if (articleText == null || articleText.trim().isEmpty()) {
            return "1 min read";
        }
        int words = articleText.trim().split("\\s+").length;
        int minutes = Math.max(1, (int) Math.ceil((double) words / WORDS_PER_MINUTE));
        return minutes + " min read";
    }
}

2. HTL Presentation & Clientlibs

HTL (HTML Template Language) provides built-in XSS protection and context-aware escaping. The template delegates all computation to our compiled OSGi Sling Model using data-sly-use.model.

Component: articleheader.html (HTL)
HTL / HTML5 
<!-- Load TechBlog CSS Clientlib -->
<sly data-sly-use.clientlib="core/wcm/components/commons/v1/templates/clientlib.html"/>
<sly data-sly-call="${clientlib.css @ categories='techblog.blog'}"/>

<header class="tb-head" data-sly-use.model="com.techblog.core.models.ArticleHeader">
  <h1>${model.title}</h1>
  <p class="tb-meta">By <strong>${model.author}</strong> | ${model.formattedDate} | ${model.readTime}</p>
  <p class="tb-body">${model.articleText}</p>
</header>
